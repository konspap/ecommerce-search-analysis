# 🔍 E-commerce Search Optimization Analysis

This repository contains my research on optimizing on-site search engines in e-commerce platforms, focusing on user behavior and business performance metrics.

Το repository αυτό περιέχει την ερευνητική μου εργασία σχετικά με τη βελτιστοποίηση μηχανών αναζήτησης σε πλατφόρμες ηλεκτρονικού εμπορίου, με έμφαση στη συμπεριφορά χρηστών και τα επιχειρησιακά metrics.

## 🎯 Objective | Στόχος

The goal of this research is to analyze how on-site search systems impact:

- User behavior  
- Click-through rate (CTR)  
- Conversion rate  
- Revenue  

Στόχος της έρευνας είναι η ανάλυση του τρόπου με τον οποίο τα συστήματα αναζήτησης επηρεάζουν:

- Τη συμπεριφορά χρηστών  
- Το Click-through rate (CTR)  
- Το Conversion rate  
- Τα έσοδα  

---

## 📊 Key Insights | Κύρια Ευρήματα

- Users follow a broad-to-narrow search behavior  
- UX improvements significantly increase conversion rates  
- Visual elements enhance engagement  
- AI is transforming search into natural language interaction  

- Οι χρήστες ακολουθούν συμπεριφορά αναζήτησης από γενικό σε πιο συγκεκριμένο  
- Οι βελτιώσεις στο UX αυξάνουν σημαντικά τα conversion rates  
- Τα οπτικά στοιχεία ενισχύουν την αλληλεπίδραση  
- Η Τεχνητή Νοημοσύνη μετασχηματίζει την αναζήτηση σε φυσική γλώσσα
