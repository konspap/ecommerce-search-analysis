# E-commerce Search Optimization Analysis

This repository contains my research paper on optimizing on-site search engines in e-commerce platforms.

## 📄 Research Paper
You can find the full paper here:
👉 [View Paper](./ecommerce-search-optimization-paper.pdf)

## 🔍 Overview
The research explores how search systems impact:
- User behavior
- Click-through rate (CTR)
- Conversion rate
- Revenue

## 📊 Key Insights
- Users follow a broad-to-narrow search behavior
- UX improvements significantly increase conversion and engagement
- Visual elements (banners, tabs) improve performance
- AI is shifting search toward natural language queries
