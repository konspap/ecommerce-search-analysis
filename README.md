## 🎯 Objective
The goal of this research is to analyze how on-site search systems impact:

- User behavior
- Click-through rate (CTR)
- Conversion rate
- Revenue generation

---

## 📊 Key Insights

- Users tend to start with broad queries and refine them (broad-to-narrow behavior)
- Improvements in UX (filters, tabs, layout) significantly increase conversion rates
- Visual elements (banners, product displays) improve engagement and session duration
- AI is transforming search into more natural language interactions
